# Advanced-Python-Time-Series-Analysis-of-Apple-AAPL-Historical-Stock-Data
For this project, I analyzed five years of Apple Inc. (AAPL) historical stock market data using Python to explore stock performance, identify trends, and apply advanced data analysis techniques.
ools & Libraries Used
Python
Pandas
NumPy
Matplotlib
🔹 Key Tasks Performed

✅ Cleaned and transformed the dataset by handling missing values, converting data types, and formatting the Date column.

✅ Performed time-series analysis to examine daily and monthly stock price trends and trading volume.

✅ Applied feature engineering by creating:

Daily Price Change
Percentage Price Change
Daily Returns
7-Day and 30-Day Moving Averages
Rolling Volatility

✅ Created visualizations to better understand:

Closing Price Trend
Trading Volume Trend
Moving Average Comparison
Daily Price Movements
